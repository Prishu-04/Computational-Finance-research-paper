How the calls are generated — the pipeline logs aggregate test-set metrics per model (experiment_log.csv) but doesn't persist a per-timestamp prediction trace. So each call here is drawn live from that model's own reported direction-accuracy against this day's true label: right with that probability, otherwise a wrong class at random. Over a full session the live accuracy converges to the reported number — it's a faithful replay of the model's real skill, not a recording of a specific inference run.
